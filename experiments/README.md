# experiments/

- `launch/<YYYY-MM-DD_label>.sh` — **one script per launch, tracked.** This is the record of what you ran; edit knobs here, never type long commands. Scaffold: `python -m explog new <label> --dataset kkp --profile a6000`; template: `launch/_template.sh`. Each script exports `SDFT_LAUNCHER`/`SDFT_LAUNCH_CMD` so the run record stores its path, sha256 and a verbatim copy (`runs/<id>/launcher.sh`).
- Two kinds of record share `runs/`: **training runs** (`kind: train`, from `main.py`) and **standalone evaluations** (`kind: eval`, from `eval_*.py` — `run.json` names the target run/checkpoint or the base model, `results.json` holds metrics + per-sample scores; the training run's `results.json` gets a pointer). The in-training eval curve stays inside the training run. Launch evals like training: `scripts/eval.sh <dataset> <run_id> [step]` or `scripts/eval.sh <dataset> base`, from a script in `launch/`. `scripts/eval.sh <dataset> teacher [n]` is the **teacher view**: the base model under the trainer's teacher prompt (demonstration in context) vs under the plain prompt, same *n* training items — one record with `teacher_accuracy` / `student_accuracy` / `gap`.
- `runs/<YYYY-MM-DD_label>/` — one folder per training run, written by `main.py` (`run.json` provenance incl. the typed launch command + env, `launch.sh` re-run script, `launcher.sh` copy of the launcher, `events.jsonl` curves, `results.json` standalone evals, `code.patch`, `notes.md` for your judgement). Tracked in git; checkpoints are not (`checkpoints/`).
- Re-run a recorded run at its exact code state: `python -m explog rerun <id> --exec` (or `bash runs/<id>/launch.sh`).
- `INDEX.md` — the glance. Generated by `python -m explog table`; never edit it, edit a run's `notes.md`.
- Judge a run: `python -m explog note <id> --validity valid|suspect|invalid --reason "…" --verdict "…"`.
- Compare / inspect: `python -m explog compare <a> <b>`, `python -m explog show <id>`, `python -m explog check`.
- Brain: `python -m explog brain-sync` writes one ledger file per run into `research-buddy/…/experiments/runs/` in the format the brain app reads.
